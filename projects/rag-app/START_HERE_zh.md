# 🚀 快速上手：1 分钟通关指南

欢迎使用 **混合动力认知 RAG 系统**！请跟随以下简单的 7 步指南，快速拉起并完整体验本系统的全部 4 大交互面板。

---

## 🏃‍♂️ 第一步：安装系统依赖
确保您的系统已安装 Python 3.9 或更高版本，然后执行：
```bash
pip install -r requirements.txt
```

---

## 💻 第二步：启动本地模型（默认离线运行模式）
如果您希望在本地完全免费地运行大模型，请确保后台已开启 Ollama 客户端，并拉取 Llama 3 模型：
```bash
ollama pull llama3
```
*(注：您也可以在启动系统后，在左侧侧边栏中随时热切换为云端 API 模式，并填入您的 OpenAI、DeepSeek 或 Groq API Key)*。

---

## 🌐 第三步：一键拉起应用
在当前目录下启动 Streamlit 网页控制台：
```bash
python app.py
```
程序启动后会自动在您的浏览器中打开前端交互页面（默认地址为 `http://localhost:8501`）。

> 🎨 **主题无缝切换（黑曜石暗黑 Obsidian 与纯净钛金 Light）**：
> 在页面右上角点击 `⋮` 菜单 -> `Settings` -> `Theme`，即可在 **Dark（黑曜石暗黑）** 与 **Light（钛金极简）** 之间随意切换。所有工控卡片、平铺导航栏与高精度操作按钮均已完美自适应双主题。

---

## 📂 第四步：上传并解析知识库文档
1. 找到右侧面板的 **"📂 Document Context Ingestion"** 区域。
2. 拖拽或上传任意一个 PDF 文件。
3. 系统会自动对其进行智能段落切片、生成向量 Embedding 并索引存入本地 ChromaDB 向量库。

---

## 💬 第五步：体验智能检索助手与性能指标 (Tab 1)
1. 在顶部居中导航栏中点击 **Tab 1: 💬 交互式智能问答助手**。
2. 在聊天框中输入一个关于您上传的文档的问题，点击发送。
3. **观察响应时延**：观察右侧 `System Controller Traces` 区域，查看本次生成的首 Token 延迟 (TTFT) 与 Token 输出速度指标。
4. **触发语义缓存秒回**：再次发送相同的问题（或语义非常相近的问题），您会发现系统通过 **语义缓存 (Semantic Cache)** 实现了**瞬时秒回 (0.00s)**，完全绕过了 RAG 和大模型生成链路。
5. **动态微调参数**：在左侧侧边栏中，您可以一键开启/关闭重排 (Rerank) 或改写 (Rewrite)，并滑动微调相似度截断阈值，实时观测 RAG 检索上下文的质变。

---

## ⚡ 第六步：体验 TypeSafe Jev 系统一极速决策网关 (Tab 3)
1. 在顶部居中导航栏中点击 **Tab 3: ⚡ TypeSafe Jev (系统一决策网关)**。
2. 在下拉框中选择预设的攻防样本（越狱攻击、混淆代码、或常规知识提问），也可以自由输入文本。
3. 动态滑动 **严苛阻断阈值 (τ_strict)** 与 **安全放行阈值 (τ_safe)**。
4. 点击 **「执行 Jev 系统一决策筛选」**，直观观察低于 100ms 的类型化原语（`Noul`, `Choice`, `Score`）如何完成极速分流拦截与放行，规避不必要的大模型 Token 损耗。
5. 切换上方单选按钮至 **「批量基准测试评估」**，对测试集运行 Jev 批量扫描，直观量化 80%+ 的大模型 Token 成本节省比例。

---

## ⚖️ 第七步：体验工具路由评测与 LLM 质量仲裁打分 (Tab 4)
1. 在顶部居中导航栏中点击 **Tab 4: ⚖️ 评测基准与仲裁打分**。
2. **确定性路由分流基准集评估**：点击 **「🚀 运行路由测试集评估」**，秒级完成对数学计算、联网时效、图谱关联与文档检索样本的意图分流判定，查看分流准确率与 0 Token 旁路率。
3. **单次问答 RAG 质量验真打分 (LLM-as-a-Judge)**：在下方输入待测试的提问、检索参考上下文与生成的回答，点击 **「⚖️ 执行 RAG Triad 质量仲裁打分」**，通过裁判模型实时判定回答的 **真实性 / 忠实度 (Faithfulness)** 与 **答案相关度 (Answer Relevancy)**。
