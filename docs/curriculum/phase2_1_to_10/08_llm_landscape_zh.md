## 🆚 闭源商业 API vs. 开源自部署权重

在构建 AI 应用时，你需要做的第一个重大架构决策是：**我们是使用云端的商业 API，还是自己部署开源模型？**

| 维度 | 闭源商业 API (如 OpenAI o1/4o, Claude 3.5 Sonnet) | 开源/开放权重模型 (如 Llama 3.3, DeepSeek-V3/R1, Qwen 2.5) |
| :--- | :--- | :--- |
| **接入难度** | ⚡ **极易**：注册账号拿个 Key，写三行 Python 代码就能用。 | 🛠️ **中等**：需要搭建显卡环境，安装 Ollama 或 vLLM / SGLang 等推理引擎。 |
| **数据隐私** | ⚠️ **存在风险**：数据需通过互联网发送给外部云服务商。 | 🔒 **绝对安全**：完全部署在本地私有机房或企业专有 VPC，数据绝不出网。 |
| **可控与定制**| ⚠️ **受限**：仅支持 Prompt 工程和厂商限定的微调接口。 | 🎯 **无限可能**：支持全量/LoRA 深度微调、模型量化融合与底层算子优化。 |
| **收费模式** | 💳 **按量付费**：按 Token 计费，支持 Prompt Caching（缓存命中可享 2~5 折优惠）。 | 🖥️ **设备成本**：买断或租赁 GPU 显卡，固定运维成本，并发使用无额外 Token 费用。 |

## 📏 读懂模型大小（参数量）与决策范式

今天的模型版图已经从纯文本生成演进到“系统一极速决策 + 系统二深度推理”的混合分层体系：

### 0. 微型与系统一决策原语 (<1B 参数)
* **代表模型**：`TypeSafe Jev`、专用轻量分类与安全 Guardrail 头。
* **特性**：70-500ms 超低延迟，零文本生成开销，直接输出校准类型化概率（`Noul`、`Choice`、`Score`）。
* **擅长任务**：安全护栏高频拦截、RAG 向量与图路由分发、Agent 工具调用前置审批，避免盲目唤起高成本 LLM。

### 1. 轻量端侧模型 (1B ~ 9B 参数)
* **代表模型**：`Llama-3.2-3B`、`Llama-3.1-8B`、`Qwen-2.5-7B`、`Gemma-2-9B`。
* **硬件要求**：普通的家用笔记本电脑、手机、边缘计算盒或廉价云 GPU。
* **擅长任务**：文本分类、单篇短文总结、简单客服对话、数据清洗并输出高准确率 JSON。

### 2. 中量级主力模型 (14B ~ 32B 参数)
* **代表模型**：`Qwen-2.5-14B/32B`、`DeepSeek-R1-Distill-Qwen-32B`。
* **硬件要求**：高端台式机（配备 RTX 4090 / 24GB 显存）或单卡云端 A10G/L4。
* **擅长任务**：日常业务代码生成、复杂逻辑判断、高质量中英双语专业翻译，高性价比。

### 3. 重量级与前沿 MoE 模型 (70B 及以上至 671B 参数)
* **代表模型**：`Llama-3.3-70B`、`Qwen-2.5-72B`、`DeepSeek-V3` / `DeepSeek-R1`（671B 混合专家架构，37B 激活参数）。
* **硬件要求**：企业级多卡 GPU 服务器集群（如 4~8 卡 A100/H100 或 H200），或超大统一内存工作站。
* **擅长任务**：前沿多步推理、竞赛级算法代码、自主多智能体编排与复杂科研公式推导。
